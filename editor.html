처음 사용하시나요? 게시 권한 연결 방법
  1. GitHub에서 게시용 키 만들기를 열고 로그인하세요.
  2. Token name에는 ‘교재 편집’, Expiration에는 원하는 유효기간을 선택하세요.
  3. Repository access에서 Only select repositories → ffsm을 선택하세요.
  4. Repository permissions에서 Contents → Read and write를 선택하고 Generate token을 누르세요.
  5. 표시된 키를 복사해 아래에 붙여넣으세요. 다른 사람이나 채팅에 보내지 마세요.

키는 GitHub에 권한을 확인할 때만 사용하며, 기기 저장소·수정본·교재 파일에는 저장하지 않습니다. 이 화면을 닫거나 새로고침하면 다시 입력해야 합니다. GitHub에서 언제든 키를 취소할 수 있습니다.
