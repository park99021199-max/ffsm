# 보험인을 위한 질병 대백과사전

학습 사이트: https://park99021199-max.github.io/ffsm/

## 현재 구성

- 6권 · 60부 · 360장의 계획 구조
- 제1권 제1~5부 및 제6부 제1장, 총 31장 설명 본문, 실무 해설, 가상 사례와 확인 문제
- 기존 공개 교재 이미지를 보존
- 장 제목 검색, 장별 고유 주소, 학습 완료 저장, 인쇄/PDF 저장

## 같은 주소에 업데이트하기

이 저장소 main 브랜치의 index.html이 기존 GitHub Pages 주소로 배포됩니다. 새 장이나 수정은 같은 저장소에서 반영하며 새 사이트 주소를 만들지 않습니다. chapters.json의 본문과 index.html의 DATA를 함께 갱신하고 실제 배포 결과를 확인합니다. 대화 작성만으로 자동 동기화되지는 않습니다.

## 자료 범위

본문은 교육용이며 사례는 모두 가상입니다. 질병분류표·진단확정 방법·보장개시·지급횟수 등은 실제 가입 계약으로 확인해야 합니다. 의학 개념과 KCD 개정은 각 장의 참고 자료를 확인하세요. 이미지 속 진행률은 제작 당시 기록이며 현재 진도는 첫 화면이 기준입니다.

## 파일

- index.html: 완결형 학습 웹앱
- chapters.json: 장별 본문과 출처
- AGENTS.md: 다음 수정 시 지켜야 할 편집·검증·배포 규칙
